# NeuroEval - Módulo AVD 🧠📱

Prototipo de apoyo a la selección de instrumentos de evaluación para personas con patologías neurológicas. Este proyecto se enfoca específicamente en el módulo de **Actividades de la Vida Diaria (AVD) Básicas e Instrumentales**.

## 📖 Descripción del Proyecto
La diversidad de instrumentos clínicos disponibles dificulta a los profesionales identificar evaluaciones pertinentes de manera rápida. NeuroEval es una solución digital diseñada prioritariamente como una **aplicación móvil**, que permite a los Terapeutas Ocupacionales agilizar el proceso de evaluación en pacientes neurológicos, sin perder el contacto visual durante la entrevista u observación clínica.


## 🛠️ Tecnologías Utilizadas
- **HTML5:** Estructura semántica con enfoque *Mobile-First*.
- **CSS3:** Sistema de diseño basado en Custom Properties (Variables) exportadas desde Figma.
- **JavaScript (Próximamente):** Para la lógica de cálculo de las escalas (sumatorias) y la navegación dinámica.

## 🤝 Proyecto Internacional COIL
Este prototipo es el resultado de un proyecto colaborativo internacional (COIL) entre tres instituciones latinoamericanas:
- 🇲🇽 **Universidad Veracruzana (México):** Diseño de interfaces de usuario e Ingeniería de Software.
- 🇨🇱 **Universidad Santo Tomás (Chile):** Terapia Ocupacional.
- 🇪🇨 **Pontificia Universidad Católica del Ecuador (Ecuador):** Fisioterapia.
